# English Words — өргөтгөлийн тайлан

## 1. Нэмсэн боломжууд

- Суралцах календарь: 12 долоо хоногийн heatmap, сар/долоо хоног, өдрийн бодит үйлдэл ба идэвхтэй зарцуулсан хугацаа.
- Цуглуулга: үүсгэх, засах, устгах, үг нэмэх/хасах, явц, flashcard, quiz, CSV/JSON экспорт. Цуглуулгыг устгахад үг болон сурсан ахиц устахгүй.
- Ухаалаг толь: англи/монгол утга, IPA, хэрэглээ, ижил/эсрэг утга, цуглуулгаар хайх; түвшин/үгсийн аймгийн шүүлтүүр; хайлтын болон нээсэн үгийн түүх.
- Өдөр/долоо хоногийн зорилго, бодит буруу хариултаас тооцсон сул үгс.
- 20 тусдаа collocation/phrasal verb, хоёр хэлний жишээ, холбоотой үг, дуудлага ба шалгалт.
- Сонсголын 5, зөв бичих 4 төрөл; ижил/эсрэг утгын шалгалт; чирэх болон дарах үйлдэлтэй өгүүлбэр бүтээх дасгал.
- Бичгийн дасгал: хувилбаруудын түүх, суурь дүрмийн орон нутгийн шалгалт, илэрсэн алдааны бүртгэл. API adapter-ийн тусдаа интерфэйстэй.
- Нөхцөл дэх хэрэглээ: суурь 30 үг тус бүрийн өдөр тутмын болон нэмэлт нөхцөлийн жишээнүүд.
- Амжилтын тэмдэг: бодит тоо, анх хүрсэн огноо, явц, дэлгэрэнгүй dialog, хөдөлгөөн багасгах тохиргоонд нийцсэн animation.
- Өдрийн сорилт: орон нутгийн огноогоор тогтвортой даалгавар, нэг удаагийн 10 оноо, түүх, нүүрний карт.
- 10 хянан оруулсан word family; CEFR тархалт, бататгасан үг, бодит хариултын зөв хувь, сарын идэвх, зарцуулсан хугацааны шинжилгээ.
- Дүрэм/бичгийн алдааны ангилал, давтах холбоосууд.
- Урьдчилан харах CSV/JSON импорт, давхардал болон буруу мөрийг алгасах, нэмэх хэлбэрийн нэгтгэл.
- Офлайн app shell/content cache, сүлжээний төлөв, эвдэрсэн локал өгөгдлийг дарж устгалгүй татаж авах сэргээх урсгал.

## 4. Navigation

Desktop-ийн 7 үндсэн хэсэг: Нүүр, Үгс, Дадлага, Дүрэм, Шинжилгээ, Өдрийн сорилт, Нэмэлт хэрэгсэл. Хажуу цэсийг хурааж болно. Mobile-ийн 5 хэсэг: Нүүр, Сурах, Дадлага, Ахиц, Профайл. Нэмэлт хэрэгслүүдийг Толь / Дадлага / Шинжилгээ гэсэн дэлгэгддэг бүлгүүдэд байрлуулсан. Хуучин шалгалт, давтлага, түүх, хадгалсан үг, виджет болон мэдэгдлийн дэлгэцүүд хэвээр.

## 5. Өгөгдлийн бүтэц

Root `version: 1`, `lexi-v1` хадгалалтыг хэвээр үлдээв. Нэмэлт `advanced.version: 1` дотор customWords, collections, practice, writing, speaking, time, goals, achievements, challenges, mistakes, searchHistory, recentWords, reminders хадгална. Үйлдэл бүр өөр ID/огноотой. Микрофоны аудио, таньсан ярианы текст хадгалахгүй; зөвхөн үг, таарсан эсэх, огноо хадгална. Бичсэн өгүүлбэрийн хувилбарууд төхөөрөмжид хадгалагдана.

## 6. Backup migration

Хуучин `advanced` хэсэггүй зөв version-1 backup-ийг зөвшөөрч, нэмэлт хоосон бүтэц үүсгэнэ. Ахиц, хуваарь, идэвхтэй шалгалт, дүрэм, favorites/difficult хэвээр. Шинэ backup-д custom ID холбоос, давхардсан record ID болон өгөгдлийн төрлүүдийг шалгана. Backup restore нь өмнөх шигээ бүх snapshot-ийг солих тул баталгаажуулалттай; vocabulary import зөвхөн шинэ үг нэмнэ. Эвдэрсэн хадгалалтыг автоматаар дарж бичихгүй.

## 9. Ажиллагааны хүрээ

Шинэ дэлгэцүүд локал өгөгдөлтэй ажиллана. Үгийн quiz болон listening зэрэг хариултууд хадгалагдана. Үгийн шинэ хуваарь зорилго, цуглуулга, сорилтын онооноос тусдаа. Шинэ сануулгын switch/цаг нь Нэмэлт хэрэгсэл хэсэгт байна; үндсэн Notifications зөвшөөрөл, master switch шаардлагатай. Өдрийн сорилт, долоо хоногийн зорилго (Ням гараг), нээлттэй дүрмийн сануулгыг нэг удаагийн delivery key-ээр хамгаалсан.

## 10. Browser / platform хязгаар

- Бичгийн шалгалт local heuristic; утга, байгалийн хэллэг, бүх дүрмийн зөв байдлыг бүрэн үнэлэхгүй. Шалгаагүй ангиллыг тодорхой тэмдэглэнэ. AI оноо зохиохгүй.
- Дуудлага/сонсгол нь төхөөрөмжийн Web Speech voice-оос, яриа таних нь browser/OS дэмжлэг ба микрофоны зөвшөөрлөөс хамаарна. Энд бодит iPhone микрофон/дуу, OS notification delivery-г туршаагүй.
- Сануулга нь апп нээлттэй үед ажиллана; хаалттай аппын push server нэмээгүй. Офлайн нээхээс өмнө нэг удаа онлайн shell cache амжилттай хадгалагдсан байх шаардлагатай. Дууны үйлчилгээ офлайнаар ажиллахгүй байж болно.
- Offline fallback-ийг cache/fetch harness-аар шалгасан; browser-ийн физик сүлжээг тасалж туршаагүй. Native file picker/drop-ийг төхөөрөмж бүр дээр туршаагүй; parsing/merge automated tests-тэй.
- iPhone Scriptable widget-ийн regression tests pass; iPhone дээр суулгах, WidgetKit/Scriptable refresh хугацаа болон гар backup sync нь платформын хязгаар хэвээр.
- Суурь 30 үг, 100 дүрэм, 20 хэллэг, 10 word family-тэй. Байхгүй хэлбэр, өгүүлбэр, түүхэн хугацаа, статистик зохиогоогүй. Цааш нэмсэн үгс contextual example-гүй бол хоосон агуулгыг үнэнээр харуулна.
- Хугацааг зөвхөн focused, visible, сүүлийн 60 секундэд үйлдэлтэй үед 15 секундын хэсгээр бүртгэнэ; өмнөх суралцсан хугацааг таамаглахгүй.

## 11. Дараагийн хөгжүүлэлт

Багшийн хяналттай A1–C1 үгийн/нөхцөлийн санг өргөжүүлэх; бодит iPhone/Android дээр audio, mic, import/drop, offline, notification smoke test хийх; тусдаа зөвшөөрсөн backend/API шаардлагатай бол cloud sync болон илүү нарийн бичгийн үнэлгээ нэмэх. Том хэмжээний олон жилийн activity-д localStorage-оос IndexedDB рүү хэмжилтэд тулгуурлан шилжүүлж болно.
